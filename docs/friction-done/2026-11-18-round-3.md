## Common causes, ranked by what they cost accuracy work

1. **Measuring was the snapshot rewrite.** Every hypothesis needed `npm run snapshots:update` (5-10 min, more behind
   the lock), which rewrites tracked files; a restart mid-run lost it; A/B meant swapping source files under running
   jobs. Five of seven reports; the cast-placement agent spent half its session waiting. Fix: a measure-only command
   on worker threads, against any commit, on a selection.
2. **The log check was visible only through verdicts.** Each diagnosis wrote three to five scratch scripts for the same
   views: placed casts and stops, the replay's landings, Stagger windows, the log's listing joined to the engine's
   modifiers, mismatches grouped by cause (with an id collision bug on the way). Fix: commands built from those
   prototypes.
3. **Long jobs were invisible and unfair.** A plain flock had no queue (a premerge starved 40 min), printed nothing
   while waiting, had no end marker to wait for, and a container restart left no trace. Fix: a ticket queue with
   priorities, heartbeats, `EFSIM-DONE` lines and run states.
4. **Engine rules had no switch.** Boss freezes and the teammates' pause were decided one way; testing the other reading
   meant patching loaded data or a temporary env switch in the engine. Fix: an engine assumption registry beside the
   kits'.
5. **What the log means was folklore.** Cast-event offsets, hidden casts, status keys, ms vs frames, abilityEvent
   numbers, what the replay copies from the log: in code comments and reports. Fix: tables in the design docs and the
   data-format doc, and pointers from the code.
