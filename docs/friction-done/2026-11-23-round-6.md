## Common causes, ranked by what they cost

1. **The kit buff's own clock had no view** (buff-clock 1, Artful Intent 1, round 5's backlog 22 from Twilight and
   Rossi: four agents, 40–60 min each). Every "runs long / short" question needs the buff's expiry on the replay's own
   clock, but the only view (`replay --kit-buff`) shows the check's window, already cut by an inferred cast's
   `expires` or held to the log's end; two agents first read that window as the natural end and were misled.
2. **Findings lived in per-worktree scratch/** (hidden-holds 1, Artful Intent 3, the lead): open-problems cited
   scratch/bc/, scratch/hh/, scratch/corrosion-lag.ts "in the session's worktree"; the next agent listed every
   worktree's scratch to find them (half an hour), copied them and patched imports. Without those worktrees on disk the
   numbers couldn't have been reproduced.
3. **Silent gaps in the tools that look like answers** (smaller-leads 2 and 3, buff-clock 4): world-time views without
   an event-placed ultimate's stop (a hold missing reads as "a hidden hold"); `hits --assume` printing the default
   reading's verdicts; `measure --hits` dying after a full run on a new fixture.
4. **The split file mixes public and secret lists** (smaller-leads 4): a new development log stayed "earlier pending"
   because registering it meant opening fixtures/holdout/holdout.json.
5. **Names against ids, readings as a variant switch** (hidden-holds 3 and 4): a check run on Gilberta's id for
   Arcane's; a temporary assumptions reading added to measure a code variant and removed again.
6. **The backlog only grows** (round 5 friction 1 and 2): 25 → 37 points, every round re-reading points nobody asked
   for again, outcome lines and carried points by scratch Python.
