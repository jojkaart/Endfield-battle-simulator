## Common causes, ranked by what they cost

1. **The replay's decisions weren't records, so every question about them was a measure or a script**
   (combo-hold points 1 and 2, away point 2, 0c14 point 2): the tail-cut rule's false positives found one 6-minute
   measure at a time (three rounds, ~20 minutes of guessing each), a reading's effect on its own target log by two `hits
   --json` runs and a scratch pairing, an inferred press printed as a skipped tick because the EVENT line matched again
   instead of reading what the replay did, a dropped kit jump visible only as an odd ratio. The costliest by far.
2. **Two compositions of one thing drift** (backlog 3, backlog 5, away point 1, combo-hold point 3): the snapshot
   check and the hit records composed the replay apart; reason strings doubled as the snapshots' kinds; the totals and
   the replay each find a fight's lives; the data's curve reading travelled apart from the data.
3. **Slow or silent feedback on the tools themselves** (0c14 points 3 and 4, away point 5, combo-hold point 4): `hits
   --all --operator` computing every log, a two-file split costing five parts, a mis-shaped scratch call running on the
   defaults, an option name clash found only at start-up.
4. **One 3,100-line file** (backlog 6): the replay's passes, one run, the holds' inputs, the crits and the hit
   readings in buffreplay.ts, found by grep.
5. **Smaller**: the totals' crit luck not split from the model (0c14 point 1), a burst's cause searched for rather than
   recorded (backlog 2), short operator names refused (away point 4), the Files line unchecked (round 13's own point 1).
