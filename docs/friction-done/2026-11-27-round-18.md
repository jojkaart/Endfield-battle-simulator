   guard, a late join to a cast, a realignment by value skipped, a mid-fight kill: each was found by a stderr print in
   the guard or a jq dump, then reverted.
2. **One measure per question where one run could answer several** (replay-only point 1, status-pairing points 1 and
   2): which of three rules in one file moved a hold-out (a reverse patch and a measure each), a constant's value (a
   commit, an edit, a diff, a revert each), a reclassification apart from a change (two scratch scripts).
3. **A hold-out's move that no blind-safe line traces** (placement-cases point 2, replay-only point 1): a data-right
   change dropped because nothing said whether a replay rule acted where the hold-out moved.
4. **Structured output missing where scripts read the views** (log-only point 1, replay-only point 2, round 17's
   point 2): rankings by share back-computed the fights' totals from the text table; cli-ab parsed the casts view by
   regexes.
5. **One view per log where the question spans logs** (log-only points 3 and 4, placement-cases point 3): a stack's
   value at each cast over 12 logs, twin bursts, the lateness across a Stagger break.
