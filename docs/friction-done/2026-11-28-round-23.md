   measured the same plain tree again (35 min); an edit during snapshots:update failed it only at its end.
4. **Views pairing or classifying by their own rule** (the team-SP report point 2, the break-combo report point 2,
   the placement-cases report point 2): the EVENT line's first-in-span cast, three rules for an ultimate event's
   press or stop's end, slots with no path.
5. **Traps and unstated rules** (the placement-cases report points 3–5, the combo-hold report points 3–4, the team-SP
   report point 4, round 22's own points 3–4): worldMs compared exactly, an expression multiplier no rule can bound, a
