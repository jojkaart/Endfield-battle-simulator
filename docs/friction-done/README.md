# Friction reports: done

Friction reports whose points have been handled, moved here from
[docs/friction/](../friction/README.md) by an improvement round, so that
folder only holds what still needs doing. Each moved report ends with a line
per point saying what was done (or why not). Each improvement round also
leaves a summary here, `YYYY-MM-DD-round-<n>.md`: the reports it read, the
common causes it found, what it changed and where.
